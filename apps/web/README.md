# aedst web

The web client for the `aedst` monorepo. It's a Next.js app that talks
directly to `apps/server`'s ConnectRPC API — no GraphQL or REST gateway in
between (see [`docs/decisions/0002-connectrpc.md`](../../docs/decisions/0002-connectrpc.md):
ConnectRPC's wire protocol is plain HTTP/1.1 + JSON/protobuf, so a browser can
call it directly).

## Tech stack

- **Next.js 16** (App Router, Turbopack) + **React 19**
- **ConnectRPC** via [Connect-ES](https://connectrpc.com/docs/web/getting-started) —
  `@connectrpc/connect` / `@connectrpc/connect-web` / `@connectrpc/connect-query`,
  with TypeScript client stubs generated by `buf` + `@bufbuild/protoc-gen-es`
  straight from `apps/server/api/proto`
- **TanStack Query** for client-side caching around Connect calls
- **next-intl** for i18n across five locales: `ar`, `en`, `ru`, `tj`, `uz`
- **Biome** for linting and formatting
- **Vitest** + Testing Library for unit tests
- **Playwright** for end-to-end tests

## Getting started

### Prerequisites

- Node.js 24+
- pnpm (see `pnpm-workspace.yaml` / the lockfile for the version)
- A running `apps/server` instance if you want real API responses (see
  `apps/server/README.md`) — by default it listens on `:8080`

### Install

```bash
pnpm install
```

### Configure environment variables

Copy `.env.example` to `.env.local` and adjust as needed:

```bash
cp .env.example .env.local
```

| Variable | Description | Default |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | Base URL of `apps/server`'s ConnectRPC API | `http://localhost:8080` |
| `NEXT_PUBLIC_SENTRY_DSN` | Sentry DSN (optional) | — |
| `NEXT_PUBLIC_BETTER_UPTIME_HEARTBEAT_URL` | Better Uptime heartbeat URL (optional) | — |

### Generate the ConnectRPC client

The TypeScript client stubs under `src/shared/api/connect/generated` are
generated (not committed — see `.gitignore`) from `apps/server/api/proto` and
must be regenerated after checkout and whenever those `.proto` files change:

```bash
pnpm connect:generate
```

This runs `buf generate` (config in `buf.gen.yaml`) against
`apps/server/api/proto`'s `auth`, `users`, and `profile` services (the
`events.proto` files are NATS event schemas, not RPCs, and are intentionally
excluded).

### Run the dev server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Testing

### Unit tests (Vitest)

```bash
pnpm test          # run once
pnpm test:watch    # watch mode
pnpm test:coverage # with coverage
pnpm test:ui       # Vitest UI
```

### End-to-end tests (Playwright)

```bash
pnpm test:e2e:prod    # builds the app, then runs against it
pnpm test:e2e:headed  # headed mode against the dev server
pnpm test:e2e:debug   # Playwright inspector
pnpm test:e2e:report  # view the last HTML report
```

### Lint / format / typecheck

```bash
pnpm lint             # biome check
pnpm format           # biome format --write
npx tsc --noEmit      # type check
```

## Project structure

```
src/
  app/            # Next.js App Router: routes, providers, env/i18n/sentry config
  modules/        # feature modules (UI + co-located i18n catalogs)
  shared/
    api/connect/  # Connect-ES transport/client setup + generated stubs
    ui/           # shared UI components (shadcn-based)
    lib/          # shared hooks/utilities
```

See `AGENTS.md` for Next.js-version-specific conventions used in this app.
