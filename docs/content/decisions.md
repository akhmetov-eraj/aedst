# Decisions index

Single index of the architectural decisions that shape the stack: what was decided, why, and **when it is legitimate to revisit**. AI agents: if a proposal contradicts a row below, do not implement it and do not re-propose it; if you believe a "revisit when" trigger has fired, say so to the owner and cite the row.

Status legend: **Accepted** (in force), **Kept** (owner explicitly decided to keep the status quo; see [Explicit rejections](/library-first#explicit-rejections-do-not-re-propose)), **Pending** (known follow-up, not done).

Verification legend: entries about Apple and Desktop were **statically reviewed only** (no Xcode / Qt toolchain in the authoring environment); the first real build is their acceptance test. Items marked `UNVERIFIED` were reported by the platform work but not independently checked by the documentation pass.

## Server

| Decision | Status | Rationale | Revisit when |
|---|---|---|---|
| Valkey (go-redis client, `AEDST_VALKEY_*`) replaces Redis; **cache and `redis_rate` only, never correctness** | Accepted | Open licence; anything that must be correct lives in Postgres ([ADR-0010](/decisions/0010-caching-and-data-partitioning)) | Valkey client ecosystem diverges from go-redis |
| RedSync removed; Postgres advisory locks (`internal/platform/lock`) | Accepted | Redlock-style locks are not safe for correctness; Postgres is already the source of truth | A lock must span systems other than Postgres |
| NATS JetStream removed; Postgres transactional outbox + Relay + in-process bus + inbox-guarded subscribers; River only for deferred jobs; `messaging.Publisher` is the seam for a future broker. **No NATS/Kafka/RabbitMQ until proven insufficient; never publish from request handlers, use the outbox.** Inbox dedupes per event type per module | Accepted | [ADR-0011](/decisions/0011-outbox-relay-and-in-process-bus) (supersedes [ADR-0004](/decisions/0004-nats-jetstream)); one fewer stateful system to run | A consumer becomes its own service, or measured relay lag cannot be fixed by batch/replicas ([scaling](/scaling)) |
| Chi kept; never `chimw.RealIP` (use `ClientIPFromXFFTrustedProxies`) | Kept | Template choice, middleware ecosystem; `RealIP` trusts spoofable headers | Never for `RealIP`; router swap only on owner request |
| Goose kept; one version table per module (`goose_<module>`); squawk migration lint (`task lint:migrations`); `sqlc vet` | Kept | Atlas is paid; per-module tables keep the modular monolith splittable | Atlas (or an alternative) becomes free and clearly better |
| Server is an OIDC resource server (jwx v4 + `jwkfetch`, `AEDST_OIDC_*`, asymmetric-only allow-list). Keycloak default (Apache-2.0), Zitadel alternative (AGPL-3.0 core since v3), Ory not recommended. New projects set `AEDST_AUTH_FIRST_PARTY_ENABLED=false`; first-party auth (argon2id, refresh rotation with CAS and reuse detection) is compatibility-only; no self-built MFA, recovery or social login | Accepted | `apps/server/docs/adr/0001-identity-provider.md` (in-repo path, not a docs-site page) | IdP licence changes; a project needs something no IdP offers |
| Observability: OpenTelemetry OTLP via standard `OTEL_*` to any backend (Grafana Cloud / SigNoz / HyperDX); local compose profile `observability` = single `grafana/otel-lgtm`; Prometheus `/metrics` optional and off by default; otelhttp + otelconnect; no self-hosted Tempo/Loki/Pyroscope by default | Accepted | Vendor-neutral, one container locally, no stateful telemetry stack to operate | A team decides to self-host a backend (then document it) |
| `connectrpc.com/validate` wired: Protovalidate annotations are actually enforced | Accepted | Annotations without enforcement are false safety | — |
| `/livez`, `/readyz`, graceful shutdown | Accepted | Kubernetes contract | — |
| Forbidden: second JWT library, ORM, Prometheus-specific instrumentation | Accepted | One primary tool per responsibility | Owner request |
| Integration tests use Testcontainers + `internal/platform/postgrestest` | Accepted | Real Postgres, no mocks for SQL | — |
| Outbox, inbox and idempotency tables are platform-owned (`platform.*` with `module` / `consumer` / `scope` columns), not copied per module | Accepted | [ADR-0012](/decisions/0012-shared-platform-messaging-tables); a module needs no tables or repository code for them | The shared outbox becomes a vacuum/bloat hotspot, or a module is extracted with its own database |
| Idempotency keys are scoped per caller and serialized with a transaction-scoped advisory lock (`internal/platform/lock`); `Idempotency-Key` is 1–128 printable ASCII | Accepted | Two same-key requests racing must execute once; users must not collide on or probe each other's keys | — |
| State transitions that publish events are guarded in SQL (`WHERE status <> 'done'`), so a repeat writes no second outbox row | Accepted | A second `event_id` slips past every consumer's inbox and duplicates the effect ([events.md](/events)) | — |
| Every append-only table has a `retention.Policy` run by a River periodic job (leader-elected), inbox retention ≥ outbox retention | Accepted | Unbounded tables were the known scaling gap ([scaling.md](/scaling#known-limits)) | Batched deletes stop keeping up: partition and drop partitions |
| Valkey is **optional at runtime**: not a startup dependency, `/readyz` reports it as `degraded` (HTTP 200), limiters fail open, the limiter-outage warning is logged at most once per 30 s | Accepted | A cache/rate-limit outage must not become a total outage on every replica; "fails open by design" has to be true end to end | Something correct starts depending on Valkey (it must not — see [ADR-0010](/decisions/0010-caching-and-data-partitioning)) |
| Server-side failures are logged with their real cause (`httpserver.ErrorLogInterceptor`) and recorded on the span; clients only ever see a generic message | Accepted | A 500 with no cause anywhere is undebuggable in production | — |
| Authorization by role is a declarative policy (`httpserver.RoleInterceptor`, procedure → allowed roles); per-user API rate limit and per-instance load shedding (`AEDST_MAX_IN_FLIGHT`) sit in front of every handler | Accepted | Handlers must not hand-roll access checks or capacity protection | — |
| The tasks module updates atomically and optimistically: single-statement partial `UpdateTask`, `version` + optional `expected_version`, idempotent `CompleteTask`/`ReopenTask`, reminder job enqueued in the task's own transaction (`InsertTx`) | Accepted | Reference behaviour every new module copies: no read-modify-write, no lost reminder, no duplicate event | — |
| Standard gRPC health (`grpc.health.v1`, driven by `/readyz`'s `Readiness`) is always served; gRPC reflection only when `AEDST_GRPC_REFLECTION_ENABLED=true` (`connectrpc.com/grpchealth`, `connectrpc.com/grpcreflect`) | Accepted | The server already speaks gRPC; balancers and `grpcurl` expect these; reflection publishes the API surface, so it is opt-in | — |
| Role policy is configuration, validated at startup: `AEDST_ROLE_POLICY` (`/pkg.Svc/Method=role\|role,…`) is parsed by `httpserver.ParseRolePolicy` and checked against the procedures derived from the protobuf descriptors; an unknown or public procedure, or a procedure with no role, **fails startup** | Accepted | A typo in an allow-list must not leave the real RPC silently open, and adding an admin RPC must not require touching wiring code | An RPC needs per-resource (not per-role) authorization: that belongs in the module's application layer |
| Alerts (`PrometheusRule`), a Grafana dashboard and a per-alert runbook ship in the Helm chart; alerts are written in native Prometheus format and reference only the server's own OTel metrics | Accepted | An SLO nobody is paged for is a wish; [runbook](/runbook) | Thresholds are re-derived from a production-shaped load test ([scaling.md](/scaling#load-testing)) |
| Production Postgres is highly available: 3 instances, one synchronous replica, PITR backups, PgBouncer pooler for the API pool, direct connection for the jobs pool (CloudNativePG manifests, or an equivalent managed service) | Accepted; manifests **unverified against a cluster** ([deployment.md](/deployment#verification-status-read-this-before-trusting-the-manifests)) | A single primary is a single point of failure for every module | The cloud target is chosen (then Terraform/OpenTofu is written for it) |
| Delivery is GitOps: Argo CD follows `main` for staging (automatic) and a release tag for prod (manual promotion) | Accepted; **unverified against a cluster** | A merge is a deployment; production changes are promoted by a person | — |
| Media ships in-process with presigned direct uploads; processing on River queue `media`, split by `AEDST_JOBS_QUEUES` | Accepted | Amends [ADR-0008](/decisions/0008-realtime-and-media-extraction) | Queue split proves insufficient (extract with `extract-service`) |
| `ObjectStorage` port with one aws-sdk-go-v2 implementation and presets for S3 / MinIO / R2 (minio-go rejected: pulls golangci-lint's tool graph) | Accepted | One S3 dialect covers all three; presign signs length + checksum | A provider needs a non-S3 API |
| Push senders built on stdlib crypto + existing jwx v4 + `x/oauth2/jwt`; webpush-go rejected (second JOSE library) | Accepted | One JOSE library rule | — |
| Every Connect service is mounted through `mountService` (protovalidate interceptor, per-service read limit, required `Connect-Protocol-Version`); no streaming RPCs while interceptors are unary-only | Accepted | Proto contract → Protovalidate → interceptor cannot be skipped; enforced by `cmd/server/rpc_test.go` | Streaming RPCs are needed (add streaming interceptors first) |
| `http.Server` timeouts/limits and security headers are env-configurable with safe defaults; HSTS only on HTTPS; CSRF = bearer tokens only + Connect header | Accepted | Senior-level baseline; see `internal/platform/httpserver/security.go` | Cookie auth is introduced (add Origin checks) |
| AdminService is closed by default (`/aedst.admin.v1.AdminService/*=admin`); admin audit entries are written in the target module's transaction through `…Tx` api methods | Accepted | Exception to "no cross-module transactions" so an audit row cannot be lost | Admin is extracted into its own service |
| Load testing with k6 (`test/load/api.js`, smoke in CI) and static analysis with go vet + staticcheck (golangci-lint v2) + govulncheck | Accepted | Gates CI can actually run | — |
