# Apple i18n

Cross-platform rules (locales, per-module ownership, content consistency) are in the [i18n overview](/i18n). This page covers only Apple.

| | |
|---|---|
| Mechanism | Xcode **String Catalog** (`.xcstrings`), one per SwiftPM target |
| Module catalogs | `Features/<Name>/Sources/<Name>/Resources/Localizable.xcstrings` |
| Why | Native since Xcode 15 and inside this repo's OS floor; holds every locale in one file per target, with no per-locale `.lproj` folders to keep in sync. |

## Status

| Module | Catalog |
|---|---|
| Common / app-shell | ✅ `App/Shared/Sources/AedstAppShared/Resources/Localizable.xcstrings`, `Core/AedstCore`, `Core/AedstDesignSystem` |
| Auth | ✅ `Features/Auth` (`authLogin*` keys, used in `LoginView.swift`) |
| Tasks, Admin, Media, Notifications, Search | ✅ `Features/<Name>/Sources/<Name>/Resources/Localizable.xcstrings` |
| Update-required screen | `appUpgrade*` in `App/Shared`, `errorUpgradeRequired` in `AedstCore`, `tasksPendingSync` in `Features/Tasks`; en, ru, tg, uz, ar |

See also [Apple architecture](/apple/architecture).
