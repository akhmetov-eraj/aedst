# AEDST docs

Architecture, module boundaries and decision records for the `aedst` monorepo — a Go backend (`apps/server`) plus four clients (`apps/web`, `apps/android`, `apps/apple`, `apps/desktop`) built around one shared principle: **monolith first, boundaries first, microservices later**.

## General

Cross-platform pages that apply to everything:

- **[Stack overview](/stack)** — headline stack per platform and how to keep versions current.
- **[Library-First Development](/library-first)** — approved libraries, order of preference, explicit rejections.
- **[Platform status & profiles](/status)** — what has actually been built and run, and the Core profile (Server + Web only).
- **[UI kit](/ui-kit)** — cross-platform design tokens and component parity.
- **[i18n overview](/i18n)** — locales and per-module translation rules.
- **[Decision records](/decisions)** — the ADRs behind the stack choices.
