# Android i18n

Cross-platform rules (locales, per-module ownership, content consistency) are in the [i18n overview](/i18n). This page covers only Android.

| | |
|---|---|
| Mechanism | Android resource qualifiers: per-module `res/values*/strings.xml` |
| Module catalogs | `feature/<name>/src/main/res/values{,-en,-ar,-tg,-uz}/strings.xml` |
| App-shell strings | `app/src/main/res/values*/strings.xml` (`common_*` keys) |
| Per-app language | `androidResources.generateLocaleConfig = true` (application convention plugin) builds `res/xml/_generated_res_locale_config` from the `values-<locale>` folders; `res/resources.properties` in `app` and `app-tv` sets `unqualifiedResLocale=ru` (the unqualified `values/` is Russian). The system language picker therefore offers exactly ru, en, tg, uz, ar |
| Why | This is the platform API: Android merges resources by name across modules at build time, so no third-party library is needed. |

## Status

| Module | Catalog |
|---|---|
| Common / app-shell | ✅ `app/src/main/res/values*` |
| Auth | ✅ `feature/auth` (`auth_*` keys, used in `LoginScreen.kt`) |
| Tasks, Admin, Media, Notifications, Search | ✅ `feature/<name>/src/main/res/values*` (all five locale directories each) |
| Shared (`core/ui`, `core/media`) | ✅ `core/<name>/src/main/res/values*` (`aedst_action_ok/cancel/confirm/retry` in `core/ui`) |

See also [Android architecture](/android/architecture).
