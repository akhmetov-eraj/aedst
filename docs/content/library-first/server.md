# Library-First: Server (Go) stack

Part of the [Library-First standard](../library-first.md). Principles, version policy, explicit rejections and the Definition of Done are in [General rules](general.md).

| Responsibility | Tool |
|---|---|
| Router | stdlib `net/http` ServeMux (Go 1.22+ patterns, `GET /livez`); chi was replaced by owner decision. Client IP: `realclientip-go` (`internal/platform/clientip`: trusted hops counted from the right of `X-Forwarded-For`, otherwise RemoteAddr); **never trust `X-Forwarded-For`/`X-Real-IP` blindly**. CORS: `rs/cors`. Load shedding (MaxInFlight): a small semaphore middleware, because neither the stdlib nor the stack libraries provide it |

| Migrations | Goose, one version table per module (`goose_<module>`); migration lint is squawk (`scripts/lint-migrations.sh`, `task lint:migrations`) |

Tests: `rivertest` (test-only, part of the river module; pulls `go.uber.org/goleak` as indirect) |

The SDK is imported only from `platform/storage` (depguard) |
| Push | `internal/platform/push` (the only package that imports these libraries): Web Push + VAPID via `github.com/SherClockHolmes/webpush-go` v1.4.0; FCM via Firebase Admin Go `firebase.google.com/go/v4` v4.22.0 (`messaging`); APNs via `github.com/sideshow/apns2` v0.25.0 (token-based auth). `golang-jwt` arrives only transitively inside these libraries (signing VAPID/APNs tokens); application tokens remain jwx v4 only. **Custom push code was rejected** (ECE/RFC 8291, VAPID/APNs JWT, OAuth exchange for FCM) |
| Play Integrity (verdict verification) | Module `internal/modules/integrity`: the official generated Google client **`google.golang.org/api/playintegrity/v1`** (`V1.DecodeIntegrityToken`; the same `google.golang.org/api` module is already a direct dependency through `option` in FCM, no new modules in `go.mod`, version unchanged). Authorization is a service-account JSON or Application Default Credentials. The verdict policy (package, freshness, `requestHash`, device level, `PLAY_RECOGNIZED`) is pure `domain`; replay protection is the Postgres table `integrity.verified_tokens` (PK = SHA-256 of the token, retention policy); rate limit is `valkey.RateLimiter`. **Disabled by default** (`AEDST_INTEGRITY_ENABLED=false`). Custom token parsing / REST calls were rejected. See `apps/server/docs/adr/0018-play-integrity-verification.md` |
| App Attest (attestation/assertion verification) | Module `internal/modules/appattest`: **custom verification code** (project security logic, ADR-0016) on top of the stdlib (`crypto/x509`, `crypto/ecdsa`, `encoding/asn1`) and **`github.com/fxamacker/cbor/v2` v2.9.6** (CBOR parsing of attestation/assertion; MIT, ~1.1k stars, released in October 2026, strict decoder limits; import allowed only inside `modules/appattest`, rule `cbor-only-in-appattest` in `.golangci.yml`). The Apple App Attestation Root CA certificate is embedded via `go:embed` (SHA-256 `1cb9823b…c932`, pinned in code and in a test); roots and clocks are injected, so tests run on a synthetic PKI. Ready-made Go App Attest libraries (`splitsecure/go-app-attest` v0.4.1, `takimoto3/app-attest` v1.3.1) were **evaluated and rejected**: 20 and 6 stars, no clock injection (`time.Now`); `takimoto3` also pulls `smallstep/pkcs7`, `appleapi-core`, `testtime` and its own CBOR parser; `splitsecure` injects roots but verifies the chain with its own hand-written code (`verify_chain.go`) without clock injection, has no storage and no counter CAS, and depends on `ldclabs/cose` and `pkg/errors`. Challenges and keys live in Postgres (`appattest.challenges`, `appattest.keys`), the counter is an atomic `UPDATE … WHERE counter < $new`, retention on both tables, rate limit is `valkey.RateLimiter`. **Disabled by default** (`AEDST_APPATTEST_ENABLED=false`). Apple's receipt / fraud metric is not implemented. See [ADR-0016](../decisions/0016-device-attestation.md) |
| Media processing | River queue `media`; images use **govips v2 + libvips** (cgo, build tag `vips`, `internal/modules/media/infrastructure/processing`): validation and a pixel limit from the header, auto-orient, EXIF/GPS stripping, canonical encoding of **the original only** (and of derivatives with AEDST business logic); sizes/WebP/AVIF on demand via **imgproxy** (`darthsim/imgproxy`, signed URLs from `internal/platform/imgproxy`, `AEDST_IMGPROXY_*`). **Do not perform the same operation in both** (govips does not do generic thumbnail/preview/optimized). `golang.org/x/image` is not used ([ADR-0015](../decisions/0015-govips-and-imgproxy-media-pipeline.md)); video/audio use external `ffmpeg`/`ffprobe` (`AEDST_MEDIA_FFMPEG_PATH`), optional |
| Delivery (Kubernetes) | **Helm** chart `deployments/helm/aedst-server` (+ `values.schema.json`, worker Deployments from `workers:`); **Kustomize** base + `overlays/<env>` for the CloudNativePG resources (`deployments/k8s/postgres`) and for the SOPS Secret; **Argo CD** Applications; secrets: **SOPS + age** decrypted by **ksops** in the Argo CD repo-server (alternative: External Secrets Operator if a cloud secret store is adopted). CNPG backups use the in-tree `barmanObjectStore` (deprecated upstream; the Barman Cloud Plugin migration is a tracked follow-up, UNVERIFIED against the operator version) |
| Query/job tracing | **otelpgx** v0.13.0 (`github.com/exaring/otelpgx`, pgx `QueryTracer`, `internal/platform/database` only) on all three pools, wrapped so a span exists only under an existing parent (River's own polling queries create no root traces); **otelriver** v0.12.0 (`github.com/riverqueue/rivercontrib/otelriver`, River middleware, `internal/platform/jobs` only) with trace propagation in job metadata and per-job spans/metrics. Versions are the latest in the Go module proxy when added; River stays v0.49.0 |
| Rate-limit tests | **miniredis** v2.39.0 (`github.com/alicebob/miniredis/v2`), test code only: it runs `redis_rate`'s Lua script in memory, so the limiter is tested without a Valkey container |
| HTTP hardening | `http.Server` with `ReadHeaderTimeout/ReadTimeout/WriteTimeout/IdleTimeout/MaxHeaderBytes` from env, TLS >= 1.2 (usually terminated at the ingress), HSTS, CSP, `nosniff`, Referrer/Permissions-Policy, body limit + per-service `WithReadMaxBytes`; CSRF: bearer tokens only + mandatory `Connect-Protocol-Version` |
| Contract → validation | Proto contract → Protovalidate → ConnectRPC interceptor: services are mounted **only** through `modulekit.Mount` (`internal/platform/modulekit/mount.go`), which always adds `connectrpc.com/validate`; a test fails on a direct `New*ServiceHandler` |
| Static analysis | `go vet`, staticcheck (in golangci-lint v2), govulncheck, in `task check` and server-ci. gofumpt (0.12.0), govulncheck (1.8.0) and goose (3.28.0) are pinned in `mise.toml` through the `go:` backend (the same versions CI used to `go install`); CI and local runs get them from mise only |
| Load testing | k6 (`test/load/api.js`: smoke/load/stress with thresholds; `task load SCENARIO=…`) |

**Events.** The transport is River ([ADR-0014](../decisions/0014-river-insert-tx-as-outbox.md)): `events.Publisher.Publish(ctx, tx, …)` inserts one job per consumer **in the same transaction** as the state change (`river_job` is the outbox). Handlers are registered in `events.Registry` and are idempotent (at-least-once; there is no inbox table); retries/backoff/discard and their retention are handled by River (`AEDST_JOBS_*_RETENTION_HOURS`). NATS JetStream/Kafka/RabbitMQ only when a consumer becomes a separate service (`events.Publisher` is the seam; **NATS is not accepted now**). **Never publish an event outside the transaction that changes state.** A state transition that publishes an event is guarded in SQL (`WHERE status <> …`) so a retry does not produce a second event. One shared platform table remains: `platform.idempotency_keys` ([ADR-0012](../decisions/0012-shared-platform-messaging-tables.md); outbox/inbox were removed). Details: [events.md](../server/events.md).

**Locks and cache.** RedSync/Redlock and any distributed locks in Valkey are forbidden; use only Postgres advisory locks. A Valkey failure must not break correctness (degradation only: no cache, rate limit fail-open/closed per module policy).

**Auth.** ZITADEL by default (AGPL-3.0: use it unmodified as a separate service, no obligations for application code), Keycloak as the alternative (Apache-2.0, if the project forbids AGPL), Ory is not recommended (see the identity-provider ADR-0001). **New projects set `AEDST_AUTH_FIRST_PARTY_ENABLED=false`.** First-party auth (argon2id, refresh-token rotation with CAS and reuse detection) is a temporary migration path with a mandatory removal date `AEDST_AUTH_FIRST_PARTY_SUNSET` (off by default; see the Sunset runbook in `docs/content/server/runbook.md`); **do not develop custom identity features** (MFA, recovery, social login), that is the IdP's area.

**Auth: operating ZITADEL.** Access tokens are JWT only (`accessTokenType` JWT for applications and machine users; an opaque token yields `auth.ErrOpaqueToken` and a warn log with a hint, not a silent 401). The audience is the project id; clients request the scope `urn:zitadel:iam:org:project:id:<projectId>:aud`. Roles come from the claim `urn:zitadel:iam:org:project:roles` (`{role: {orgId: domain}}`), with `projectRoleAssertion` enabled; `AEDST_OIDC_ROLES_ORG` (optional) restricts roles to one organization. Service-to-service uses ZITADEL machine users (client credentials or JWT profile), not Keycloak service accounts. ZITADEL uses the same CloudNativePG cluster with **a separate database and a separate role** and connects directly (not through PgBouncer in transaction mode). The official Helm chart `zitadel/zitadel-charts` is Apache-2.0, an optional dependency for `idp` (example values in `apps/server/deployments/zitadel/`). Password hash import: `apps/server/deployments/zitadel/import-users.sh` (UNVERIFIED, see runbook). No new libraries were added to the application.

**Observability.** No self-hosting of Tempo/Loki/Pyroscope by default. Locally: the compose profile `observability` (a single `grafana/otel-lgtm` container). In production: Grafana Cloud/SigNoz/HyperDX or another OTLP backend. Prometheus `/metrics` is optional and **off by default**.

**Realtime.** There is no WebSocket library in `go.mod`. When the product needs realtime, the candidate is `coder/websocket`, wrapped in `internal/platform/**` (not used from `internal/modules/**`), plus an entry in [decisions.md](../decisions.md).

Forbidden: an ORM instead of sqlc; a second job queue; **a second JWT/JOSE library** and hand-written JWT; a custom router; a custom validation framework; a new HTTP framework; **Prometheus-specific instrumentation** (use the OpenTelemetry API); a new event broker without proven need; a custom distributed lock; a custom rate limiter; RedSync; NATS.

## Enforcement

Every mandatory library or boundary above is a build failure, not a convention. Gates run in `task server:lint` (golangci-lint, tidy check) and `task server:arch` (`go test ./architecturetest/...`); each has a negative self-test that proves it can fail (`task server:lint:selftest` for the lint rules, a `*Reject*`/`*Missing*` test next to each architecture test).

|---|---|---|
| Direct `go.mod` requires are approved, and the list changes together with this page | `architecturetest/dependencies_test.go` `TestDirectRequiresAreApproved` against `architecturetest/approved_modules.txt`; `task server:tidy:check` (go.mod/go.sum tidy, compared before/after so a dirty tree is fine) | `TestApprovalCheckRejectsUnapprovedRequire` |
| Prometheus client only in `platform/observability`; jwx only in `platform/auth`; OTel exporters only in `platform/observability`; zap/logrus/zerolog nowhere; `cmd/**` imports a module only through `<module>/module` | `.golangci.yml` depguard rules `prometheus-only-in-observability`, `jwx-only-in-auth`, `otel-exporters-only-in-observability`, `no-second-logger`, `TestModuleBoundaries` (loads `cmd/...` too, so `cmd/**` may import only `<module>/module`; depguard cannot express that without listing every module) | `scripts/lint-selftest.sh`; `TestBoundaryCheckers` |
