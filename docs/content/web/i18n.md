# Web i18n

Cross-platform rules (locales, per-module ownership, content consistency) are in the [i18n overview](/i18n). This page covers only Web.

| | |
|---|---|
| Mechanism | [next-intl](https://next-intl.dev) JSON, one file per locale per module |
| Module catalogs | `src/modules/<name>/i18n/{ar,en,ru,tj,uz}.json` |
| App-shell strings | `src/app/config/i18n/common/*.json` |
| Tajik code | directory `tj` (every other platform uses `tg`) |
| Why | Approved stack pick in [Library-First](/library-first#web); Web is the source of truth every other platform ports from. |

## Status

| Module | Catalog |
|---|---|
| Common / app-shell | ✅ `app/config/i18n/common` |
| Auth | ✅ `modules/auth/i18n` |
| Tasks | ✅ `modules/tasks/i18n` |

Each new module gets its own `i18n/` folder — never add keys to another module's catalog. See also [Web architecture](/web/architecture).
